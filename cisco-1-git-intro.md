## Module 2: Basic Switch and End-Device Configurations

![Console shortcut reference table on a plain background, with columns Keystroke and Description. It lists: Tab — Completes a partial command name entry; Backspace — Erases the character to the left of the cursor; Ctrl+D — Erases the character at the cursor; Ctrl+K — Erases all characters from the cursor to the end of the command line; Esc D — Erases all characters from the cursor to the end of the word; Ctrl+U or Ctrl+X — Erases all characters from the cursor back to the beginning of the command line; Ctrl+W — Erases the word to the left of the cursor; Ctrl+A — Moves the cursor to the beginning of the line; Left Arrow or Ctrl+B — Moves the cursor one character to the left; Esc B — Moves the cursor back one word to the left; Esc F — Moves the cursor forward one word to the right; Right Arrow or Ctrl+F — Moves the cursor one character to the right; Ctrl+E — Moves the cursor to the end of command line; Up Arrow or Ctrl+P — Recalls the previous command in the history buffer, beginning with the most recent command; Down Arrow or Ctrl+N — Goes to the next line in the history buffer; Ctrl+R or Ctrl+I or Ctrl+L — Redisplays the system prompt and command line after a console message is received.](<images/Hot Keys.png>)

![Cisco IOS command reference page on a plain light background. A note explains that the Delete key is not recognized by the IOS command structure. The first table describes controls at the --More-- prompt: Enter Key displays the next line; Space Bar displays the next screen; any other key ends the display and returns to the previous prompt, except y, which answers yes and acts like Space Bar. A sentence introduces commands for exiting an operation. The second table says Ctrl-C ends configuration mode and returns to privileged EXEC mode, or aborts setup to the command prompt; Ctrl-Z ends configuration mode and returns to privileged EXEC mode; Ctrl-Shift-6 is an all-purpose break sequence for aborting DNS lookups, traceroutes, pings, and similar operations. The page has a clear, instructional tone.](<images/Hot Keys 2.png>)
