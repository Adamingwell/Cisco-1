## G. Reflection

### G.1 In your own words, what is the difference between Git and GitHub?

**Git is a command to track changes to files on your computer allowing you to save versions and go back to earlier work.  
  
GitHub is a website where you store Git repositories online, share your work, and collaborate with others.**

### G.2 Why is your private key kept secret, and what is the public key for?

**Your private key proves your identity. If somebody gets it, they can impersonate you.  
Your private key is shared with github so you don't have to enter your private key every single time.**

### G.3 What is the difference between git add, git commit, and git push?

**Git add is used for adding files that you changed to be committed and pushed to the repository.  
Git commit stages your files to be pushed to your repository.  
Git push adds the changed files to your repository.**

### G.4 Why would you run git pull before you start working?

**Git pull will give you the most recent version of the repository.**

### G.5 Give one example of a good commit message and explain why it is clear.

**git commit -m "First change to this repository"**
